# PoundTech favicon assets

The site uses the approved red-and-white PoundTech P emblem on a carbon-black background.

## Repository assets

- `favicon.svg` — primary scalable browser favicon (512 × 512 viewBox)
- `favicon-16x16.svg` — small browser icon
- `favicon-32x32.svg` — standard browser icon
- `favicon-48x48.svg` — larger browser / Windows tile source
- `apple-touch-icon.svg` — 180 × 180 mobile touch icon source
- `poundtech-app-icon.svg` — 512 × 512 scalable app icon
- `poundtech-logo-mark.svg` — transparent standalone emblem
- `site.webmanifest` — web app icon and theme configuration

The root `index.html` references the favicon variants and web manifest.

## Raster export sizes

The matching PNG/ICO export package is supplied separately:
- favicon-16x16.png
- favicon-32x32.png
- favicon.ico (16 × 16)
- apple-touch-icon.png (180 × 180)
- favicon-512x512.png
- poundtech-app-icon-512.png
- poundtech-logo-mark-transparent.png (1024 × 1024)

Keep the emblem artwork unchanged when exporting other sizes.
