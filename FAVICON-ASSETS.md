# PoundTech favicon assets

The site uses the red-and-white PoundTech emblem on a carbon-black app-icon background.

## Files committed in this repository

- `favicon.ico` — 16 × 16 ICO fallback for browsers
- `favicon.svg` — scalable SVG browser favicon
- `favicon-16x16.png` — 16 × 16 PNG
- `favicon-32x32.png` — 32 × 32 PNG
- `favicon-48x48.svg` — 48 × 48 SVG
- `favicon-512x512.png` — 512 × 512 PNG
- `apple-touch-icon.png` — 180 × 180 PNG for Apple touch shortcuts
- `poundtech-app-icon-512.png` — 512 × 512 PNG app icon
- `poundtech-app-icon.svg` — scalable app icon
- `poundtech-logo-mark.svg` — transparent standalone emblem
- `site.webmanifest` — web app name, theme and icon configuration

The root `index.html` references the browser favicon sizes, ICO fallback, Apple touch icon and web manifest.

The raster and vector versions are committed to the repository root. Keep the emblem artwork unchanged when exporting additional sizes.
